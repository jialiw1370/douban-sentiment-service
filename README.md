# Douban Sentiment Service

Turn Douban movie comments into a sentiment classifier you can call from an
API: paste a Chinese movie comment, get back positive or negative with a
confidence score.

This rebuilds the author's 2024 Data Science III notebook
("Movie sentiment analysis", 10M+ Douban comments) as a real NLP service.
The notebook sampled comments, used jieba + TF-IDF, and counted NRC lexicon
emotions in the top 100 comments — but it never trained a classifier, so it
had no accuracy or F1. This project adds exactly that: a labeled train/test
split, a TF-IDF + Logistic Regression baseline with measured scores, a
comparison against a pre-trained Hugging Face Chinese sentiment model, and a
FastAPI service around the winner.

## Results (measured, test set = 20,000 comments)

| Method | Accuracy | F1 (positive) |
| --- | --- | --- |
| TF-IDF + Logistic Regression baseline (Day 3) | 0.7938 | 0.7984 |
| NRC lexicon word counting, old notebook method (Day 4) | 0.4742 | 0.1484 |

- Baseline details: 100,000 labeled comments (50,000 negative from Star 1–2,
  50,000 positive from Star 4–5; Star 3 dropped), 80/20 stratified split,
  TF-IDF with jieba tokenizer (40,423-word vocabulary). Negative precision
  0.81 / recall 0.77; positive precision 0.78 / recall 0.82. Confusion
  matrix: [[7711, 2289], [1835, 8165]].
- Why the lexicon method scores below chance (0.4742): 8,209 of the 20,000
  test comments contain no lexicon word at all (ties are predicted
  negative), and the lexicon holds 1,960 negative words vs 1,013 positive
  ones, so it over-predicts negative — it found only 916 of the 10,000 true
  positives. The trained model beats it by 32 points of accuracy.
- Error patterns (Day 4): false negatives are shorter on average (29.9
  chars vs 36.1 for correct predictions); mistakes cluster on sarcasm
  ("MDZZ。讲个笑话…"), negation ("没有传说中的烂"), and mixed reviews that
  end on the opposite sentiment.

## Data

`all_movies_with_id.csv` — 10,310,982 Douban movie comments (10,269 movies),
columns include `Star` (1–5) and `Comment`. The file was lost, then found
again — copy it into the repo root and run `python3 check_data.py` to verify
it (row count, Star distribution, lexicon check). The same file is also
public on Hugging Face as a backup:
https://huggingface.co/datasets/dirtycomputer/douban_movie_review

The CSV is ~2.3 GB on disk and gitignored — never commit it. The lexicon
file (`Chinese-Simplified-NRC-EmoLex.txt`) stays local too for now, so
don't `git add` it either. Labels come from `Star`: 1–2 = negative,
4–5 = positive, 3 = neutral (dropped for the v1 binary classifier).

## How it works (once built)

1. **Labels:** `Star` 1–2 → negative, 4–5 → positive.
2. **Baseline:** jieba tokenize → TF-IDF → Logistic Regression, 80/20 split.
3. **Comparison:** a pre-trained Hugging Face Chinese sentiment model, run
   zero-shot on the same test set.
4. **Service:** FastAPI `POST /predict` returns the label + confidence.

## Setup

```bash
python3 -m pip install -r requirements.txt
python3 check_data.py      # Day 1: verify data + lexicon
python3 build_sample.py    # Day 2: build the 100k labeled sample
python3 train_baseline.py  # Day 3: first accuracy + F1
python3 evaluate.py        # Day 4: error analysis
python3 score_lexicon.py   # Day 4: old lexicon method, same test set
python3 save_model.py      # Day 5: save model.joblib
python3 -m pytest test_model.py -v   # Day 5: tests for the saved model
```

On this Mac, use `python3`. (On Windows it would be `py`.)

`model.joblib` is generated by `save_model.py` and gitignored — it is not
committed. Clone the repo, run the steps above, and it is rebuilt locally.
